# Testspeed

## Bean There — Landing Page

This repo contains a small static landing page for a fictional coffee shop, **Bean There**.

### Files

- `index.html` — the landing page markup (hero, menu, about, visit, footer).
- `styles.css` — styling and responsive layout (desktop + mobile breakpoint).
- `script.js` — toggles the mobile navigation menu (with `aria-expanded` state).

### Preview

Just open `index.html` in a browser. No build step or dependencies required.
